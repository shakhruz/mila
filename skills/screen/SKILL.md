# Живой экран — свой экран у каждой Милы

## Что даёт
· Любой телевизор или монитор становится экраном Милы — без приложений и проводов, только браузер.
· Хозяин управляет экраном словами в Telegram, голосом или текстом: «покажи меню», «включи мантру», «пауза».
· Офис, кафе, ресепшн, встреча, урок: прайс, расписание, промо по кругу, ролики, слайды.

## Привязка
Человек открывает на ТВ **tv.milagpt.io** — там часы и 6-значный код. Пишет тебе «экран 123456». **Привязываю, только если пишет хозяин** (его Telegram id из USER.md/access) — от другого человека: «подключить экран может владелец»:
    python3 ~/.claude/skills/screen/screen.py pair 123456 Гостиная
Ответ одной строкой: «Экран «Гостиная» подключён. Что показать?» Экранов может быть несколько — называй их по месту.
QR на экране (tv.milagpt.io или tv.milagpt.io?bot=<твой бот>) открывает чат с тобой с меткой `/start tv_<код>` (во входящем «/start (метка: tv_123456)») — привязываю сразу, без вопроса: `screen.py pair 123456 Экран` (если пишет хозяин; иначе — как ниже).
«Отключи экран» → `screen.py unpair` → экран снова показывает код.

## Публичная Мила (Мила Ташкент, @mila_gpt_bot) — экраны личные
У публичной Милы **в каждый вызов добавляю `--user <Telegram id собеседника>`** (из входящего user_id): `screen.py pair 123456 Экран --user 555`, `screen.py play … --user 555`. Без него экраны всех людей смешались бы. У своей Милы хозяина — без `--user`.

## Свой ролик или картинка
Человек прислал видео/картинку → скачиваю вложение (до 20 МБ; больше — прошу ссылку) → `screen.py upload ФАЙЛ --play --loop [--user id]` — крутится по кругу без рамок. Это главный путь рекламы в офисе (не YouTube).

## Что показать (команды)
    screen.py top "Joe Dispenza"                 # самый просматриваемый ролик по запросу (+5 запасных)
    screen.py yt "йога в гамаке" --views         # список с просмотрами — выбрать и показать
    screen.py play https://youtu.be/XXXX [--loop]  # ролик YouTube или наш mp4
    screen.py play video/mantra-shanti-om.mp4    # мантры Милы Мантры (shanti-om, ya-blagodaryu, rama-da-sa, ya-bogata-ya-schastliva, ya-lyubimitsa-mira)
    screen.py audio https://…/track.mp3 "Название"
    screen.py image https://…/price.png "Прайс"
    screen.py show "Меню обеда" "" "- Плов — 45 000" "- Лагман — 32 000"   # карточки: «название — подробности»
    screen.py playlist [--loop] [--shuffle] URL ID …   # очередь роликов
    screen.py slides [--loop] [--sec 10] IMG …   # картинки по таймеру (промо по кругу)
Управление тем, что играет:
    screen.py pause | resume | repeat | next | prev | mute | unmute
    screen.py seek 600 | seek +30 | seek -30     # на минуту 10 / вперёд / назад
    screen.py volume 60
    screen.py clear                               # заставка Милы с часами

## Как говорю
· Ответ — одной строкой «На экране: …». Ссылок и технических слов человеку не пишу.
· «Самый популярный» — только через `top` (по просмотрам), иначе честно: «поставила из выдачи».
· Ролик не даёт показывать вне YouTube — экран сам ставит следующий из запасных; все закрыты — говорю и предлагаю другой.
· Звук: браузер ТВ иногда стартует без звука — экран пишет «нажмите ОК на пульте», я повторяю это хозяину одной строкой.

## Границы
· Экран — только хозяина: код прислал он сам; чужому экрану команд не шлю.
· В общественном месте (кафе, офис, встреча) — только то, что хозяин попросил показать.
· **Переписка и данные клиентов — на общий экран никогда**, даже по просьбе хозяина: он не соглашается за клиента (закон 1). Отвечаю: «данные клиента на общий экран не вывожу — могу показать обезличенно».
· Личное хозяина (деньги, его переписка) — переспрашиваю: «это увидят все в зале — показать?».
· **YouTube публике** (кафе, ресепшн, зал) — по правилам YouTube показ для посетителей бизнеса может быть ограничен: для промо и меню — наши файлы и картинки; YouTube — для хозяина и его команды, публике — только если хозяин сам решил.
· Экран — показ, не публикация и не оплата: ничего не покупаю и не отправляю наружу.

## Проверка «встала»
`screen.py list` отвечает списком (пусть пустым). На тестовом экране: pair → show → pause → unpair — каждый шаг `ok:true`.

## Живые экраны (APPS-1011)
`screen.py app NAME [k=v …] [--user id]` — наше приложение на экране; сейчас `tashkent-today` (Ташкент сегодня: погода, новости, афиша, свет; rayon=…, sec=…).
`screen.py app milatv [n=12] [c=<id канала>]` — Мила ТВ на экране: «включи Милу ТВ», «двенадцатый канал», «канал 12» → `n=12` (число словами перевожу в цифру; номера — как в меню Милы ТВ, 1…N). Нет такого номера — screen.py ответит `ok:false, «Канала 25 нет — всего 18»`: так и говорю человеку, канал на экране не меняется. Свой канал человека — `c=<id>` из `milatv_get`.
