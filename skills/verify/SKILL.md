# Проверка с цитатой

Образец — навык проверки из методики «выбор процесса» (владелец, 16.10.2026: «берём себе»).
Смысл: результат силы проверяет не автор своим впечатлением, а чек-лист самой силы — по готовому тексту, с цитатой.

## Что на входе
- **Результат** — готовый текст или файл, который сила собирается выдать. Только он. Что обсуждали в чате до этого — не источник:
  «наверное, учла, просто не написала» не считается.
- **Чек-лист** — раздел «Готово, если» из `SKILL.md` этой силы. Другого списка нет: своих пунктов не добавляю,
  даже если кажется, что чего-то не хватает.
- Раздела «Готово, если» у силы нет — пишу это одной строкой и не проверяю: проверять нечем.

## Как проверяю
Проверяющий — **отдельный исполнитель**: если движок умеет субагента, запускаю проверку им и даю ему только результат,
«Готово, если» и выводы инструментов (для пунктов-действий). Тогда «чат не источник» — устройство, а не честность.
Субагента нет — проверяю сама, по тем же правилам.

По каждому пункту «Готово, если» — три вещи: номер, вердикт, дословная цитата из результата в кавычках.
- **ДА** — есть цитата, которая закрывает пункт.
- **НЕТ** — подходящей цитаты нет. Пересказ своими словами вместо цитаты — тоже НЕТ. Сомневаюсь — НЕТ.
- **Пункт-действие** («файл сохранён», «письмо отправлено», «будильник поставлен») — цитата здесь не из текста, а **улика из
  вывода инструмента**: путь файла, id сообщения, строка журнала. Нет вывода инструмента — НЕТ, «по памяти» — не улика.
- **НЕ ПРОВЕРИТЬ** — пункт написан без признака, который можно найти в тексте («достаточно подробно»).
  Не пройден; чинить его — в навыке силы, не здесь.

Показали не результат (обрывок переписки, вопрос, пустой файл, черновик «ещё не готово») — сразу ЗАДЕРЖАТЬ
и одна строка, почему это не результат.

## Вердикт — последней строкой
- **ГОТОВО** — все пункты ДА.
- **ЗАДЕРЖАТЬ: п.2, п.4** — хоть один НЕТ или НЕ ПРОВЕРИТЬ. Результат не выдаю как финальный, пока не исправлено.
Несколько результатов — каждый отдельно, в конце «готово k из n».

## Чего не делаю
- Не переписываю результат и не предлагаю правку — только вердикт. Исправляет сила.
- Не поддакиваю: «почти подходит», «в целом соответствует» — не вердикты.
- Не показываю проверку хозяину целиком, если он не просил: ему — результат и строка «проверка: 5/5».
  ЗАДЕРЖАТЬ — исправляю и проверяю снова; дважды подряд ЗАДЕРЖАТЬ — говорю хозяину, какой пункт не сходится.

## Готово, если
1. У каждого пункта «Готово, если» силы стоит ДА, НЕТ или НЕ ПРОВЕРИТЬ.
2. У каждого ДА — дословная цитата из результата в кавычках.
3. Последняя строка — «ГОТОВО» или «ЗАДЕРЖАТЬ» с номерами непройденных пунктов.

## Как выглядит халтура
1. ДА без цитаты или с пересказом «там про это есть».
2. Свой пункт, которого нет в «Готово, если» силы («ещё бы добавить…»).
3. ДА по памяти разговора, а в самом результате этого нет.
4. Вместо вердикта — исправленный результат.
