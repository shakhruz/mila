# Живые кадры — ролик из голоса

## Что даёт
Текст → голос → ролик 16:9 (или 9:16), где на каждом важном слове что-то появляется: новый элемент каждые 1–4 с, сцена 3–6 с. Без съёмки, без стоков, без генерации картинок — всё рисует код (Pillow + numpy + ffmpeg). Рендер ≈ 5–6 мин на минуту ролика на CPU.

## Как (по шагам, каждый — с уликой)
1. **Сценарий «понятно школьнику».** Крючок-ситуация за 5 с · одна мысль — одно предложение до 12 слов · новое понятие через бытовое сравнение · цифра — с понятным сравнением и из источника с датой · обязательный блок «теперь честно» (ограничения, риски) · в конце одно действие на неделю · прощание. Проверка: пересказывается одной фразой. Источники — отдельным файлом рядом.
2. **«Да» владельца на текст и объём** (знаки ≈ секунды: 877 зн. ≈ 60 с). Без него не озвучиваю.
3. **Голос.** ElevenLabs `/text-to-speech/<voice>/with-timestamps` (модель eleven_multilingual_v2): сразу даёт таймкоды букв → слова (`golos.words.json`). Голос Милы — Anna. Чужой голос — только по согласию человека.
4. **Сверка распознаванием** (бесплатно, локально): `python3 tools/stt_words.py stt/golos.mp3` (STT_MODEL=small хватает; запускать без `-I`, иначе нет numpy). Имена, цифры, ударения — сверить с текстом; ошибочную фразу переозвучить. Слитные концовки разводить паузой 0,4–0,5 с через ffmpeg (atrim + anullsrc + concat) и сдвигать таймкоды слов.
5. **Сцены.** `spec.py`: VOICE, W/H, SCENES. Время каждого элемента = t0 слова из `golos.words.json`. Палитры: dark — основное, blue — «что случилось», warm — главные цифры и задание. Элементы: text, icon (Twemoji из tools/emoji), glass, pill, count, bar, arrow, ring, strike — подробно в шапке `tools/motion.py`. Образцы: `primery/`.
6. **Сборка.** `python3 tools/motion.py spec.py out.mp4` — фон, наезд камеры, вспышки-переходы, «вжух/поп/тики/удар», подложка с приглушением под голос, −14 LUFS.
7. **Приёмка глазами.** Лист кадров каждые 3 с (`ffmpeg … select=not(mod(n\,90)),tile`): ничего не вылезает за край, текст не налезает, у каждого элемента есть время `at` (без него сцена падает). Громкость `ebur128`.
8. **Показ** владельцу файлом + кнопки; публикация — только по его «да» на этот ролик.

## Чего не делаю
- Не озвучиваю без «да» на текст; не выдумываю цифры — только из источника с датой.
- Чужие видео и стоки без лицензии — нет. Twemoji — CC-BY 4.0 (подпись в tools/emoji/LICENSE-NOTE.txt), шрифт PT Sans — OFL.
- Значок без смысла («оранжевая точка») — нет: каждый элемент показывает сказанное слово.
