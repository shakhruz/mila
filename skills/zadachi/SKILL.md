# Задачи · предложить и раздать

1. Беру из BACKLOG.md, NOW.md и целей владельца 3–7 дел, которые двигают его цель сейчас (не «всё подряд»). Администратору — и команде.
   Каждое — `python3 ~/.claude/skills/kartochki/kartochki.py task --task … --why … --to <кто> --due … --est … --prio …`.
2. Показываю по одной: `kartochki.py next proposals` → `text` + `buttons`, первой строкой «Задачи · N».
3. Нажатие → `kartochki.py button "[кнопка] …"`:
   - «✅ Да» → строка в tasks.md исполнителя (себе — сразу `task.py new`, если стоит mila-tasks) и ей записка «Новая задача от владельца: …»;
   - «✏️ Изменить» → «Что поменять?», переписываю и выдаю ту же задачу заново (`task` с новым текстом);
   - «Нет» → снята, не предлагаю её снова без нового повода;
   - «➡️ Другой Миле» → «Какой?», `answer <id> --move <slug>`.
4. Колода кончилась — «Задачи розданы: N из M» одной строкой.
Срок и оценку называю честно; стоимость — только внешние траты в $.
