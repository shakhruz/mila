# Карточки владельцу · один формат для чата и мини-аппа

вопросы ко мне и задачи команде — одной колодой, в чате и в «Офисе Мил». Файлы веду сама:
`~/work/inbox.jsonl` (мои вопросы владельцу) и `~/work/proposals.jsonl` (мои предложения задач). Строку руками не пишу — только скриптом.

## Вопрос владельцу
    python3 ~/.claude/skills/cards/cards.py ask --q "Выкладываем партию сайта сейчас?" \
      --why "Пять готовых дел ждут одного «да»." --opt "a|Да, выкладывай|Через 5 минут на сайте" --opt "b|Подожди|Партия ждёт" \
      --rec a [--due 2026-10-15T18:00:00+05:00] [--urgent] [--link https://…]
- вопрос ≤12 слов, одно решение (навык plain-words); «почему сейчас» — 1–2 строки;
- 2–3 варианта, у каждого — что будет; рекомендация — моя, с ⭐;
- срочно (`--urgent`) — только если завтра будет поздно.
Скрипт отказывает с причиной (длинно, код задачи в тексте, рекомендация не из вариантов) — переписываю, а не обхожу.
Ответ — `text` и `buttons` для reply: отправляю владельцу как есть.

## Задача команде
    python3 ~/.claude/skills/cards/cards.py task --task "Перевести три статьи блога на EN и UZ" \
      --why "Гости из поиска не уходят" --to kontent --due 2026-10-17 --est 90 [--cost 4] --prio 2
prio: 1 срочно · 2 важно · 3 когда будет время. `--cost` — только внешние траты в $, подписку не считаю.

## Нажатие кнопки
Нажатие приходит «[кнопка] <подпись>» — передаю как есть:
    python3 ~/.claude/skills/cards/cards.py button "[кнопка] ⭐ Да, выкладывай"
Ответ `ask: edit` / `ask: move` — спрашиваю одной строкой «Что поменять?» / «Какой Миле передать?», потом
`answer <id> --edit "…"` / `--move <slug>`. «💬 Поясни» — объясняю подробнее и снова показываю ту же карточку.
Голос/текст вместо кнопки — `answer <id> --text "…"`. Вопрос потерял смысл — `answer <id> --close "почему"`.

## Границы
- Деньги, наружу, необратимое — «да» владельца на карточке и есть разрешение на этот шаг; «Реши сама» — не разрешение тратить.
- Тайна клиента в карточку не идёт: карточку видят на экране офиса.
