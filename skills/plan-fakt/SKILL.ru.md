# План-факт недели — один пост-листалка

Часть ритма недели (canon/WEEK-RHYTHM.md): понедельник — план, пятница — план-факт. Владелец получает один пост, который листает, а не простыню текста.

## 1. Факты — только из своих файлов
`python3 ~/.claude/skills/plan-fakt/scripts/collect.py > ~/work/tmp/plan-fakt.json` — черновик недели из:
- `~/work/WEEK.md` — план недели (строки-галочки и строки 🟢🟡🔴⚪);
- `~/work/state/day-<дата>.json` пн–пт — пульты дня: сделано с уликой, ждут, переходит;
- `~/work/MONEY.md` — **только если ведёте деньги**; нет файла — нет слайда и плиток про деньги.
Нет источника — «нет данных», не догадка. За каждой цифрой — улика, которую можно открыть.

## 2. Слайды
Перепишите черновик своими словами (обложка — вывод недели одной фразой), 3–5 строк на слайд, строка ≤ 60 знаков. Слайды: план · сделано · ждёт вашего слова (+ деньги, если есть). Затем
`python3 ~/.claude/skills/plan-fakt/scripts/make_slides.py ~/work/tmp/plan-fakt.json ~/work/tmp/plan-fakt/` → s1…sN.jpg (1080×1080). Каждый слайд откройте и посмотрите до отправки. Chromium находится сам; если нет — `CHROME_BIN`.

## 3. Отправка — одним постом-листалкой
- плагин mila-telegram со слайдшоу: `reply` с `slideshow: true`, `files` — слайды, `text` — HTML поста;
- иначе: `python3 ~/.claude/skills/plan-fakt/scripts/send_slideshow.py <чат владельца> post.html s1.jpg …`.
HTML поста — по `post-template.html`: заголовок · «Главное» · 📋 план · 💰 деньги (только с MONEY.md) · ⏳ ждёт вашего слова; между разделами — пустой абзац; подробности (клиенты, команда, уроки) — в `<details>`.
Сразу ответом на пост — кнопки «❓ Дай вопросы (N)» и «✅ Принял», пост — в закреп.

## 4. После
В WEEK.md — «План-факт недели N» (что сделано, что нет и почему). Понедельничный план начинается с него.

## Нельзя
- Слайды 4:5 и вертикальные — листалка их обрезает. Только квадрат.
- Несколько отдельных фото вместо одного поста-листалки.
- Разделы без пустых строк; «Подробнее» одной кашей.
- Цифры без улики; цифры чужой компании в своём шаблоне.
