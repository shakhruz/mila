# Экзамен: экспресс и живой

Слово владельца 17.10.2026 (1874): «быстро прогоняем, а живую симуляцию — периодически, для проверки».

## Один набор сценариев
- Сценарии — один yaml: id, title, say (реплики гостя, «[кнопка] X» — нажатие), must, must_not, required (обязательные), nosell/skip (не гоняется внутри).
- Экспресс и живой читают **тот же** yaml — иначе баллы несравнимы.

## Экспресс — после каждой правки (минуты)
- Тот же промпт, что в бою (в шапке прогона — sha256 промпта), модель как в бою, свежая сессия на сценарий, реплики по очереди.
- Оценка — отдельный ход модели по must / must_not → pass/fail + дословная цитата. Инструмент: `bun tools/express_exam.mjs --yaml exam.yaml --prompt PROMPT.md [--extra разметка-моста.md] --repeat 3` (нужны Bun и Claude Code с подпиской).
- `--repeat 3`: каждый сценарий трижды, итог «k из 3» — разброс модели виден, а не прячется.
- Подложенные провалы: заведомо плохой ответ (прайс списком, «выставим завтра», служебная метка) — оценка обязана сказать «не сдано». Не поймала — оценке не верим.
- Не покрывает: навыки дома (если не грузятся), мост (кнопки, счёт, «не продавать») — это тесты моста и живой прогон. Строкой в шапке.

## Живой — раз в сутки ночью (и для сверки)
- Юзербот пишет боту как гость. Перед каждым сценарием — **полный сброс гостя**: сессия, картинки, приветствие, язык, метка, счётчик ходов, карточки, счета, заявки — всё по этому id, только для тестовых id.
- Сверка экспресс ↔ живой по пунктам; расхождение — разбор, какой из двух врёт.

## Цикл
Провал → урок строкой → правка промпта или моста → экспресс (минуты) → живой ночью. Третье одинаковое замечание — в правила (self-check).

## Готово, если
- Обязательные сданы, подложенные провалы пойманы, sha промпта в шапке совпадает с боевой.
