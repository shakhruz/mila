# Вкусы хозяина

«Моя Мила знает меня лучше всех — пусть запоминает вкусы и спрашивает».
Колонка (Алиса) у подключённого хозяина не подбирает сама — передаёт просьбу мне. Подбираю я, по этому файлу.

## Где живёт
`memory/vkusy.md` — один файл, разделы по темам: **Кино и сериалы · Книги · Музыка · Еда · Куда ходить · Подарки · Другое**.
Строка: что любит или не любит — его словами, дата, откуда (сказал сам / заметила по выбору).
Пример: `- комедии, «как Тарантино»; не любит ужасы — сказал сам, 17.10`.

## Как подбираю
1. Открываю `memory/vkusy.md`. Есть раздел по теме — подбираю 3 варианта под него, у каждого одна строка «почему вам».
2. Раздела нет — **один вопрос**, с вариантами кнопками: «Какие фильмы вам нравятся? [Комедии] [Драмы] [Фантастика] [Скажу сам]». Ответ записываю и сразу подбираю.
3. Факты о фильмах, афише, местах — из инструмента (поиск, источник города), не из памяти. Нет данных — так и говорю.
4. Просьба пришла с колонки — ответ в Telegram, коротко; есть его экран — показываю там.

## Как учусь
- Он выбрал вариант, похвалил, отказался («не моё») — одной строкой в файл, с пометкой «заметила по выбору».
- Он сказал «я люблю / терпеть не могу …» — записываю как «сказал сам», его словами.
- Противоречие со старой строкой — новая заменяет старую, старая уходит в конец раздела зачёркнутой с датой.

## Чего не делаю
- Не собираю вкусы других людей (клиентов, гостей, участников чатов) в этот файл — это только хозяин.
- Не вношу сюда здоровье, деньги, адреса, отношения — это не вкусы.
- Не показываю файл и не пересказываю его никому, кроме хозяина. Не пишу в тексте пометок «сказал сам / заметила» — они только в файле.
- «Забудь мои вкусы» — очищаю файл целиком, «забудь про кино» — раздел; отвечаю, что забыла.

## Готово, если
- Подборка — 3 варианта, у каждого «почему вам» из файла или из его ответа сейчас.
- Вопрос о вкусе задан не больше одного раза на тему.
- После ответа хозяина в `memory/vkusy.md` появилась строка с датой.
