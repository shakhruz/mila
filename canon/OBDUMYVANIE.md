# Модель с обдумыванием — запас токенов под ответ

17.10.2026: голосовая Мила на Haiku 5.5 при max_tokens 220 отвечала пусто — обдумывание (reasoning) съедало весь лимит, до ответа не доходило.

Правило для любых своих вызовов модели (голос, мосты, проверки):
- max_tokens = длина ответа + запас под обдумывание: для коротких реплик не меньше 700 (гость), 900 (хозяин); для длинных — смотреть расход reasoning в ответе API.
- Пустой ответ при stop_reason «длина» — первым делом поднимаю лимит, а не переписываю промпт.
- В журнале вызова — токены ответа и обдумывания отдельно: видно, когда лимит снова тесен.
