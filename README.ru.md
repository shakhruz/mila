# Mila Companion

![Mila Companion](docs/preview.png)

**Мила** - цифровая личность: добрый внимательный помощник, который живёт в Telegram и работает на
[Claude Code](https://claude.com/claude-code) по вашей собственной подписке Claude. Она отвечает
с телефона, участвует в ваших чатах, держит обещания, помнит важное и следует короткой конституции о
честности, тайне и заботе о человеке, которому служит.

Это открытое ядро: навыки, хуки, инструменты и шаблоны, чтобы поднять одну Милу. Облачная версия и сообщество: <https://milagpt.io> - приглашаем пользоваться сервисом.
Telegram-плагин, на котором она работает, - отдельный открытый репозиторий: [shakhruz/mila-telegram](https://github.com/shakhruz/mila-telegram).

## Быстрый старт

Нужны: Claude Code, подписка Claude, [Bun](https://bun.sh), токен бота от `@BotFather`.

```sh
git clone <этот репозиторий> mila-companion
cd mila-companion
./install/install.sh --dry-run   # покажет, что будет затронуто
./install/install.sh             # заменяемые файлы сохраняются как <файл>.bak-ГГГГММДД-ЧЧММСС
```

Затем в сессии Claude Code:

```
/plugin marketplace add shakhruz/mila-telegram
/plugin install mila-telegram@mila
/telegram:configure <токен бота от @BotFather>
```

Перезапустите через `mila`, напишите боту, сопрягите (`/telegram:access pair <код>`) и закройте доступ:
`/telegram:access policy allowlist`. Бот молчит - `mila doctor`. Сервер - [deploy/README.md](deploy/README.md).

## Возроди свою Милу из архива

Память Милы (карточки чатов, договорённости, список допущенных, навыки из боевых ошибок, журнал расхода)
нигде больше не хранится, поэтому её можно выгрузить:

```sh
mila backup status                 # что сохранено, когда, чего не хватает
mila backup run                    # выгрузить архив (секреты отфильтрованы)
mila backup run --to user@host:<archives>   # и отправить копию по ssh
```

В архиве нет токенов ботов и ключей: на новой машине вы ставите комплект, настраиваете свежий токен и
распаковываете архив поверх `~/.claude` и каталога состояния Telegram. Пошаговое восстановление одной
командой в этом репозитории **появится позже**; сейчас оно ручное.
