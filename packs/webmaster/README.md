# Пакет «Вебмастер» · опциональный (не ставится с ядром) · 13.10.2026
Сайт клиента: исходники и сборка, проверка перед выкладкой, выкладка через хост-службу без токена в контейнере, журнал партий.
Ставится Миле, которая ведёт сайты клиентов: `update.py install-skill packs/webmaster/<навык> --from "<администратор>"` по каждому навыку пакета.
Состав на витрине — 9 навыков (hallmark, MIT); здесь пока `webmaster` (обобщён: пример — условный клиент `acme`, без имён настоящих клиентов).
Остальные навыки пакета переносятся сюда из витрины тем же обобщением.
